# References {#sec:references}

This bibliography records the external standards, primary data products, and
software-practice literature used to delimit the design. In-text citations use the
bracketed-key form: official OBS and obs-websocket documentation define the host/plugin
boundary [@obsmodules; @obswebsocket], NOAA SWPC's product catalogue and named feeds
define the telemetry provenance [@noaaswpc; @noaaf107; @noaasunspot; @noaartsw], and reproducibility guidance motivates the
claim-to-artifact protocol [@nasem2019; @wilson2014; @sandve2013; @wilkinson2016fair].
Software is treated as a first-class, version-specific research output according to
the FORCE11 software-citation principles [@smith2016softwarecitation], and the
repository's machine-readable citation metadata follows the Citation File Format
schema [@cffschema].
The provenance vocabulary is contextualized with W3C PROV-O [@prov2013], and the
deterministic figure pipeline cites Matplotlib [@hunter2007matplotlib]. The φ and DSP
sections cite historical mathematical context and signal-processing foundations
[@livio2002golden; @smith2007]; the H-alpha anchor is sourced to NIST [@nisthalpha].

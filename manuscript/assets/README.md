# assets/

Versioned manuscript assets: `obs/` holds the promoted live-OBS evidence
bundle (scene render, telemetry HUD, audio tone/silent captures, controlled
WAV, operator-context screenshot) with its machine manifest
`obs/obs_manifest.json`. Analytical figures are NOT stored here — they are
generated into `../../output/figures/` by `scripts/generate_figures.py`.

Part of the DataTools lane (local-only, never committed). Parent: `../README.md`.

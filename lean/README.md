# lean/

Lean 4 invariant scaffold for SynthOBS — a Lake project pinning the console
shape (3 modes x 7 buttons, shared common prefix, disjoint mode-unique ids),
fail-closed SWO/provenance acceptance predicates, and the pinned phi /
EGS-gateway literals. Build with `cd lean && lake build` (toolchain pinned in
`lean-toolchain`; see AGENTS.md). Contents: SynthOBS/, SynthOBS.lean,
lake-manifest.json, lakefile.lean, lean-toolchain.

Part of the DataTools lane (local-only, never committed). Parent: `../README.md`.

## What this is

The two OBS integration layers, with a deliberate division of labor:

- `synthobs/` — the **obspython bridge**: a single `synthobs_console.py`
  loaded via OBS Tools → Scripts; imports the tested engine
  (`../src/synthobs`) instead of maintaining a second command
  implementation.
- `fractisynth/` — the **native C libobs plugin**: three filters + a
  generated console source, with local kernels (SWO, rtsw telemetry parser,
  SHA-256, 8x8 font) for the contracts that must execute inside OBS. Its
  constants (`EGS_PHI`, `K_EGS`) are pinned and checked against the Python
  engine by `tests/test_plugin_artifacts.py` and
  `tests/test_c_parity_behavioral.py` (CI job `native-parser`).

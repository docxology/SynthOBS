## What this is

The real-input test suite for the `synthobs` engine (17 test modules;
per-file coverage map and the no-mock/real-I/O policy live in `README.md`
and `../docs/testing.md`). Run with the project's own config
(`pyproject.toml`: `testpaths = ["tests"]`, coverage `fail_under = 90`):

```bash
uv run pytest tests/ --cov=synthobs --cov-fail-under=90
```

`conftest.py` holds shared fixtures; `test_docs_contracts.py` pins doc
numbers and figure-manifest entries, so prose claims in README/status docs
fail here when they go stale. `test_lean_invariants.py` checks the Lean
scaffold for `sorry`/custom axioms and runs `lake build` when a toolchain is
available. No mock frameworks: HTTP is exercised with `pytest-httpserver`,
numerics with real concrete inputs (including NaN/±Inf batteries in
`test_fail_closed_fuzz.py`).
